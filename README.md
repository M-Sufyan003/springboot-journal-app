# Spring Boot Journal App

A RESTful Journal Application built with **Spring Boot** and **MongoDB** while learning backend development.

## Technologies

- Java 8
- Spring Boot 2.7.16
- Spring Data MongoDB
- Maven
- MongoDB

## Features

- CRUD REST APIs
- MongoDB Integration
- Layered Architecture
- Spring Boot Best Practices

## Project Structure

```
src
 ├── main
 │   ├── java
 │   └── resources
 └── test
```

## Getting Started

### Clone

```bash
git clone https://github.com/M-Sufyan003/springboot-journal-app.git
```

### Run

```bash
./mvnw spring-boot:run
```

or

```bash
mvn spring-boot:run
```

## Learning Goals

This project is being developed by following a Spring Boot tutorial while focusing on:

- REST API Development
- MongoDB
- Spring Security
- JWT Authentication
- Backend Best Practices
- Clean Architecture
